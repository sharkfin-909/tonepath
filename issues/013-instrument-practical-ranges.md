## Question

For each instrument in the v1 list from [Instrument view](011-instrument-view.md) — flute, violin, trombone, vibraphone, B♭ trumpet, B♭ clarinet, B♭ soprano sax, B♭ tenor sax, E♭ alto sax, E♭ baritone sax, F horn, guitar, double bass / bass guitar — what is the **practical written range** (lowest and highest written note a competent player reliably plays; not altissimo / extreme), in scientific pitch notation, and its transposition to concert? Cite a standard orchestration / instrument reference for each and note where sources disagree (and for bass guitar vs double bass, whether one range serves both). Deliver a table ready to paste into the spec.

## Resolution

Researched 2026-11-12. Findings, sources and per-instrument notes: [research/instrument-practical-ranges.md](../research/instrument-practical-ranges.md).

Practical **written** ranges in scientific pitch notation (C4 = middle C), with written = concert + interval:

| Instrument | Written range | Transposition | Concert range |
|---|---|---|---|
| Flute | C4–C7 | unison | C4–C7 |
| Violin | G3–E7 | unison | G3–E7 |
| Trombone | E2–B♭4 | unison | E2–B♭4 |
| Vibraphone | F3–F6 | unison | F3–F6 |
| B♭ trumpet | F♯3–C6 | up M2 | E3–B♭5 |
| B♭ clarinet | E3–A6 | up M2 | D3–G6 |
| B♭ soprano sax | B♭3–F♯6 | up M2 | A♭3–E6 |
| B♭ tenor sax | B♭3–F♯6 | up M9 | A♭2–E5 |
| E♭ alto sax | B♭3–F♯6 | up M6 | D♭3–A5 |
| E♭ baritone sax | B♭3–F♯6 | up P8 + M6 | D♭2–A4 |
| F horn | C3–G5 | up P5 | F2–C5 |
| Guitar | E3–E6 | up P8 | E2–E5 |
| Double bass / bass guitar | E2–G4 | up P8 | E1–G3 |

- **One range serves double bass and 4-string bass guitar.** Both use the same E1–A1–D2–G2 tuning and are written an octave up.
- **Sources:** Vienna Symphonic Library *Instrumentology*, the Symphony Orchestra Library Center range table, and McGill's *Timbre and Orchestration Resource* (saxophones).
- **Brass, clarinet and violin tops are judgement calls** taken from those sources' wording ("as a rule", "in orchestral playing"). The professional ranges are higher: trumpet C6/D6, clarinet C7, trombone F5, horn written F♯2–C6, violin A7.
- **Saxophone top:** F♯6 here; sources range from F6 to G6.
